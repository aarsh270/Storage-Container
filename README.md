This is my first CAD project!

It is a Storage Container, like the ones that are used to organize small things like screws, allen keys, small tools, etc.

I made it by using Fusion360 and Onshape(at school).

The main things I learned is how to use the basics of CAD, including but not limited to: sketches, shapes, extrusions, fillets, arcs, cuts, and also thin extrusions.

It consists of a main 4x4 organizer, with an additional recessed platform on the top to temporarily store objects that may be needed frequently.
The caddy has a handle, with fillets for a better feel.
